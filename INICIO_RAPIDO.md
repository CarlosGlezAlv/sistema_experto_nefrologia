# 🎉 BIENVENIDO - Sistema Experto de Nefrología

## ✨ ¡Tu proyecto está listo!

Se ha creado una aplicación profesional de diagnóstico de enfermedades renales usando:
- **React 18 + TypeScript** (Frontend)
- **Tau-Prolog** (Motor de inferencia)
- **Vite** (Build tool)

---

## 🚀 INICIO INMEDIATO (3 pasos)

### Paso 1️⃣: Abrir terminal en la carpeta `frontend`

```bash
cd frontend
```

### Paso 2️⃣: Instalar dependencias

```bash
npm install
```

### Paso 3️⃣: Ejecutar

```bash
npm run dev
```

**→ El navegador se abrirá automáticamente en `http://localhost:5173`**

---

## 📥 ¿Qué falta?

Solo necesitas descargar **2 archivos** del motor Prolog:

1. [tau-prolog.js](http://try.tau-prolog.org/js/tau-prolog-0.3.0.js)
2. [tau-prolog-lists.js](http://try.tau-prolog.org/js/tau-prolog-lists-0.3.0.js)

Coloca ambos en: **`frontend/public/`**

(Ver pasos detallados en `INSTRUCCIONES_EJECUCION.md`)

## 🏃 WORKFLOW TÍPICO

1. **Abres la app** → Pantalla de bienvenida
2. **Haces clic** en "Iniciar consulta"
3. **Respondes preguntas** sobre síntomas (20 preguntas)
4. **Sistema analiza** con Prolog
5. **Ves diagnósticos** con confianza % y tratamientos
6. **Exploras** la base de conocimiento si lo deseas
